# Claude Phone Assistant + мини-Claude на рабочем столе

[English version](README.md)

Личный ассистент для Android, который помогает не залипать в ленты, и маленький блочный Claude, который живёт на панели задач Windows. Оба работают **на твоей подписке Claude Code**: телефон отправляет запросы на ПК, а ПК отвечает через `claude -p`. Ключ API не нужен.

> Неофициальный любительский проект, не связан с Anthropic.

## Что умеет

**Телефон (Android)**
- Считает Reels / Shorts / TikTok и закрывает ленты после дневного лимита. Чтобы войти, объясняешь зачем, и Claude решает, пустить ли на несколько минут.
- Рилсы из сторис не считаются.
- Утренняя сводка и виджет 4×2: сколько роликов, следующее событие в календаре и «!», когда ты нужен Claude Code на ПК.
- Чат с мини-Claude или с настоящими сессиями Claude Code по проектам на ПК (по каналу на проект).
- Важные уведомления из мессенджеров и почты показываются облачком над питомцем на ПК. Реклама и коды подтверждения отсекаются.
- Интерфейс на русском и английском.

**ПК (Windows)**
- Мини-Claude ходит по панели задач, сидит с ноутбуком, пока работает Claude Code, и машет с «!», когда задача готова. Клик покажет последнее сообщение Claude Code.
- Клик открывает чат. Его можно перетаскивать.
- Кнопка 🖥️ в чате: Claude смотрит на экран или (красный режим) сам кликает и печатает, с кнопкой «Стоп» и правилами безопасности.
- Внутри работает «мозг» для телефона на порту 8787.

## Что нужно

- ПК с Windows 10/11:
  - [Claude Code](https://claude.com/claude-code), установлен и выполнен вход (`claude` работает в терминале);
  - [Node.js](https://nodejs.org) 20+;
  - [Android Studio](https://developer.android.com/studio), только для сборки приложения (ставит SDK и Java).
- Телефон на Android 12+ с режимом разработчика и отладкой по USB или Wi-Fi.
- [Tailscale](https://tailscale.com) на обоих устройствах, под одним аккаунтом: так телефон достаёт до ПК откуда угодно. Без него работает только по кабелю.

## Установка

### 1. Запусти мини-Claude на ПК

```powershell
git clone https://github.com/SusGoing/claude-phone-assistant.git
cd claude-phone-assistant
.\pc\start-pet.cmd
```

Первый запуск ставит зависимости (Electron, nut.js) и создаёт `pc\.brain-token`, случайный секрет для запросов с телефона. Мини-Claude добавляет себя в автозагрузку; выключается в меню по правому клику.

### 2. Собери и установи приложение

Подключи телефон (кабель или `adb pair` / `adb connect` для отладки по Wi-Fi) и запусти:

```powershell
.\build-and-install.ps1
```

Скрипт берёт `ANDROID_HOME` и `JAVA_HOME`, если они заданы, иначе стандартные пути Android Studio. Проект временно монтируется как диск `B:`, потому что Gradle ломается на кириллице в пути.

### 3. Свяжи телефон с ПК

```powershell
.\pc\connect-phone.ps1
```

Скрипт передаёт приложению адрес ПК в Tailscale и токен. Можно ввести и вручную: **Настройки → Мини-Claude на ПК**, адрес `http://<IP ПК в Tailscale>:8787`, токен из `pc\.brain-token`.

### 4. Дай разрешения на телефоне

В приложении: **Настройки → Доступы**, включи:
- **Слежение за лентами** (специальные возможности): считает ролики и показывает барьер.
- **История использования**.
- **Сообщения и почта → облачко на ПК** (доступ к уведомлениям).
- **Календарь**: для следующего события в сводке и виджете.

И в настройках Android поставь приложению батарею **«Без ограничений»**, чтобы система его не убивала.

## Как это устроено

```
Телефон ──HTTP (Tailscale, токен)──► мини-Claude (Electron, :8787) ──► claude -p (твоя подписка)
                                     └─ читает ~/.claude/projects, чтобы знать, чем занят Claude Code
```

- Запросы «мозга» запускают `claude -p` в пустой временной папке, с коротким системным промптом и без MCP, чтобы тратить меньше токенов.
- Запросы с `127.0.0.1` (сам ПК или телефон через `adb reverse`) идут без токена, через Tailscale — только с токеном.
- Управление экраном идёт через MCP-сервер (`pc/pet/screen-mcp.mjs`), который запускает только мини-Claude. Не больше 40 действий; останавливается по кнопке «Стоп» или клику по питомцу.

## Важно знать

- Интерфейс питомца на ПК пока только на русском; приложение на телефоне — на русском и английском.
- Питомец работает только на Windows.
- Smart App Control или антивирус могут ругаться на неподписанные программы. Не отключай их, проекту это не нужно.
- Запросы расходуют лимиты твоей подписки Claude. Решения по лентам и проверка уведомлений идут через Haiku и короткие.
